# aigile-ecommerce

Simplified e-commerce (catalog, cart, coupons, orders) built as the Module 6 practical project of an AI-assisted development course.

## Course deliverables

Besides the files the skills produce, the course requires these docs (in Portuguese). Save each skill output at the matching path:

| Step | Skill | File |
| --- | --- | --- |
| Scaffolding spec | `/to-spec` | `docs/scaffolding-specification.md` |
| Scaffolding blueprint | `/to-tickets` | `docs/scaffolding-blueprint.md` |
| Scaffolding review | `/code-review` | `docs/scaffolding-review-report.md` |
| Cart FRD | `/to-spec` | `docs/carrinho/frd-carrinho.md` |
| Cart blueprint | `/to-tickets` | `docs/carrinho/blueprint-carrinho.md` |
| Cart review | `/code-review` | `docs/carrinho/review-carrinho.md` |
| Cart tests | `/tdd` | `docs/carrinho/testes-carrinho.md` |
| Seeds | — | `docs/seeds-report.md` |
| Cart E2E | `/tdd` | `docs/carrinho/e2e-report-carrinho.md` |
| Cart security | `/security-review` | `docs/carrinho/security-report-carrinho.md` |
| Reverse engineering | `/to-spec` (fresh session) | `docs/carrinho/reverse-frd-carrinho.md`, `docs/carrinho/compare-frd-carrinho.md` |

## Agent skills

### Issue tracker

Specs and tickets live as markdown files under `docs/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary, recorded as a `Status:` line in each ticket. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
